## Reglas de accesibilidad automáticas (checklist)

### Contraste mínimo
- Texto normal (< 18px): ratio 4.5:1
- Texto grande (≥ 18px o ≥ 14px bold): ratio 3:1
- Componentes UI e iconos: ratio 3:1
- Herramienta de verificación: `oklch()` con L channel < 0.45 sobre fondo blanco es seguro

### Tamaños mínimos
- Body text: 16px (1rem) en desktop, 15px en mobile
- Caption / label: no menor de 12px (0.75rem)
- Target táctil: 44×44px mínimo (WCAG 2.5.5)
- Target recomendado mobile: 48×48px

### Focus y navegación teclado
- Focus ring visible: outline de 2px mínimo con offset de 2px
- Color de focus: diferente al color de borde del elemento
- Orden lógico de tab (no manipular tabindex sin justificación)

### Imágenes y media
- Alt text en todas las imágenes informativas
- Alt text vacío `alt=""` en imágenes decorativas
- Videos: subtítulos automáticos o manuales disponibles
- No usar color como único indicador de estado

### Formularios
- Label asociado a cada input (no usar placeholder como único label)
- Mensajes de error descriptivos y cercanos al campo
- Agrupar campos relacionados con `fieldset`/`legend`
